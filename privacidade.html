Política de Privacidade — Conexa Uploader

Última atualização: 11/11/2026.

O que é

O Conexa Uploader é um aplicativo de uso interno que envia vídeos para canais do YouTube pertencentes à Conexa, usando a YouTube Data API v3.

Dados acessados

Apenas a conta do proprietário do canal, que autoriza o acesso, com as permissões de enviar vídeos e ler dados básicos do próprio canal. Não acessamos dados de outros usuários.

Uso e armazenamento

O token de autorização fica guardado somente no computador da empresa, não é compartilhado, vendido nem usado para publicidade. Os dados obtidos servem apenas para enviar e agendar vídeos do próprio canal.

Compartilhamento

Não compartilhamos dados com terceiros. O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogar acesso

O proprietário pode revogar o acesso a qualquer momento em myaccount.google.com/permissions.

Conexa Uploader is an internal app that uploads videos to YouTube channels owned by Conexa via the YouTube Data API v3. It accesses only the authorizing channel owner's own channel data, stores the token locally, and does not share, sell or use data for advertising. Use of Google API data adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
